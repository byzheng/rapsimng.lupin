# rapsimng.lupin

Lupin model for APSIM Next Generation.

## Installation

Currently on [Github](https://github.com/byzheng/rapsimng.lupin) only.
Install with:

``` r

remotes::install_github('byzheng/rapsimng.lupin')
```
